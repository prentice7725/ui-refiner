水と米と、冬の仕事。

酒井酒造は明治四年、兵庫県のこの町で酒造りをはじめました。仕込みに使うのは、創業のころから蔵の敷地で汲みつづけている井戸の水です。山から時間をかけて下りてきた水は、口あたりがやわらかく、酒の味を静かに支えてくれます。

米は、地元の農家さんと話をしながら選んだ兵庫県産の山田錦が中心です。純米大吟醸は四割まで、純米酒は六割まで磨き、米の味わいがどこまで残るかを見ながら、一つひとつの仕込みを決めています。

仕込みは毎年十一月から三月まで。蔵人が交代で泊まり込み、蒸し米と麹ともろみの様子を確かめます。醸造アルコールは加えず、すべて純米でお造りしています。
