ABOUT

家にいるように、
のんびり過ごせる場所

ひだまりの家は、所沢市の住宅街にある定員25名のデイサービスです。大きな施設ではないぶん、職員が利用者さん一人ひとりの顔と好きなことを覚えて、毎日声をかけています。

朝はご自宅までお迎えにうかがい、夕方にはまたお送りします。日中は体を動かしたり、お風呂に入ったり、お昼ごはんを食べながらおしゃべりしたり。無理なく、その方のペースで過ごしていただけるようにしています。

ご家族が安心してお仕事や用事に出られるよう、その日の様子は連絡帳でお伝えします。

FAQ

よくあるご質問

利用を始めるまでの流れを教えてください。

おおまかには次のとおりです。

  1. お電話かお問い合わせフォームでご相談
  2. 見学・体験（ご家族とご一緒にどうぞ）
  3. 担当のケアマネジャーさんと利用日などを調整
  4. ご契約のうえ、利用開始

要介護認定をまだ受けていない方は、市役所や地域包括支援センターへのご相談からになります。わからないことがあれば、お電話でお尋ねください。

費用はどのくらいかかりますか。

介護保険の自己負担分は、要介護度と負担割合、ご利用の時間によって変わります。昼食代など、保険の対象にならない費用も別にかかります。

くわしい金額は、見学の際やお電話でご説明します。

見学や体験はできますか。

はい、月曜から土曜の営業時間内でしたらいつでもどうぞ。日程を合わせますので、事前にお電話かフォームでお知らせください。

送迎はしてもらえますか。

ご自宅まで送迎します。送迎できる地域や時間は、お住まいによって変わりますのでお問い合わせください。

週に何日から利用できますか。

週1日からご利用いただけます。ケアマネジャーさんと相談して、ご本人とご家族に合った曜日を決めましょう。
