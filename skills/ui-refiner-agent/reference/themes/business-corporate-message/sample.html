Message

目立たない部品だからこそ、
手を抜かない。

フィルターは、設備の奥で黙って働く部品です。きちんと機能しているときほど、その存在は意識されません。

1972年に東大阪の町工場から始まった私たちは、その見えない仕事をひとつずつ積み重ねてきました。これからも、お客様の現場の水と空気を確かな品質で支えてまいります。
