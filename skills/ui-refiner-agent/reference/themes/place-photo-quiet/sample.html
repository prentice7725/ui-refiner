路地の奥に、
八つの部屋。

渋温泉の石畳を少し入ったところに、しずく庵はあります。客室は八つだけ。源泉は加水も加温もせず湯船にそそぎ、夕食は奥信濃の山と畑のものを、その日の分だけ仕込みます。

館内には内湯がふたつと貸切の露天風呂、湯上がりに休める囲炉裏の間。外湯めぐりから戻ったら、部屋でゆっくり過ごしてください。
